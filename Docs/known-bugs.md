## Reporting New Bugs

If you encounter a bug not listed here, please report it by following these steps:

1. Check if the issue is already listed in this document
2. Create a detailed description including:
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Browser/device information
   - Screenshots if relevant
3. Submit the issue to our issue tracker

We appreciate your help in making Typer-99 better!
